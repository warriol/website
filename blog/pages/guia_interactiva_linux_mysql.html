Etapa 1: Configuración de la Máquina Virtual

Crearemos un entorno seguro para practicar sin afectar tu computadora principal.

1. Habilitar Virtualización

Es un ajuste clave en tu PC. Para verificar en Windows, abre el Administrador de Tareas (`Ctrl + Shift + Esc`), ve a la pestaña 'Rendimiento' y asegúrate de que 'Virtualización' esté 'Habilitada'.

2. Instalar VirtualBox

Descarga el instalador desde el sitio oficial de VirtualBox. La instalación es estándar, puedes aceptar todas las opciones por defecto.

3. Crear una Nueva VM

  • Abre VirtualBox y haz clic en 'Nueva'.
  • Nombre: "Debian-MySQL"
  • Tipo: Linux, Versión: Debian (64-bit)
  • Memoria RAM: 2048 MB (2 GB)
  • Disco Duro: 'Crear un disco duro virtual ahora', tipo 'VDI', 'Reservado dinámicamente', con un tamaño de 20 GB.

Etapa 2: Instalación de Debian 12

Instalaremos un sistema operativo Linux minimalista, perfecto para aprender a usar la terminal.

1. Descargar la Imagen de Debian

Ve a la página de descargas de Debian y obtén la imagen ISO de la versión 12 ("Bookworm"). Elige la opción 'netinst' que es más ligera.

2. Instalar en la VM

Inicia tu VM en VirtualBox. Te pedirá un disco de inicio; selecciona el archivo ISO que descargaste.

  • Elige la opción 'Graphical install'.
  • Configura tu idioma, ubicación y teclado.
  • Crea una contraseña de root y una cuenta de usuario. ¡Anótalas!
  • Para el particionado del disco, la opción más simple es 'Guiado - utilizar todo el disco'.
  • En la selección de software, desmarca todo excepto 'SSH server' y 'standard system utilities'. No necesitamos una interfaz gráfica.

Etapa 3: Configuración de la Base de Datos

Instalaremos MariaDB (una versión de MySQL) y crearemos una base de datos de prueba.

1. Instalar y Asegurar MariaDB

Inicia tu VM y accede con tu usuario. Ejecuta estos comandos en la terminal:

# Actualizar la lista de paquetes
sudo apt update

# Instalar el servidor y cliente de MariaDB
sudo apt install mariadb-server mariadb-client

# Asegurar la instalación
sudo mysql_secure_installation

Durante `mysql_secure_installation`, establece una contraseña de root para la base de datos y responde 'y' (sí) a las preguntas de seguridad.

2. Crear Base de Datos y Tabla de Prueba

Ahora, entraremos a la consola de MariaDB para preparar nuestro entorno de práctica.

-- Entrar a la consola
sudo mysql -u root -p

-- Crear la base de datos
CREATE DATABASE tienda_virtual;

-- Usar la nueva base de datos
USE tienda_virtual;

-- Crear una tabla de productos
CREATE TABLE productos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(255) NOT NULL,
    precio DECIMAL(10, 2) NOT NULL,
    stock INT DEFAULT 0,
    categoria VARCHAR(100)
);

-- Insertar datos de prueba
INSERT INTO productos (nombre, precio, stock, categoria) VALUES
('Laptop', 1200.50, 50, 'electronica'),
('Teclado mecánico', 85.00, 150, 'perifericos'),
('Mouse gaming', 45.75, 200, 'perifericos'),
('Monitor 27"', 350.00, 75, 'electronica');
