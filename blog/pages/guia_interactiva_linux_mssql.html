Guía de Instalación de Servidor Virtual

Un recorrido interactivo para instalar Debian 13 con MSSQL Server en una máquina virtual usando VirtualBox.

🖥️ ¿Qué es una Máquina Virtual?

Imagina que es como tener una computadora completa dentro de tu computadora actual. Te permite ejecutar otro sistema operativo (como Linux, en este caso) en una ventana, sin afectar tu sistema principal (Windows). Esto es perfecto para aprender, desarrollar y probar software en un entorno aislado y seguro.

1

Instalar Oracle VirtualBox

Primero, necesitas el programa que te permitirá crear y gestionar las máquinas virtuales. Se llama Oracle VirtualBox y es gratuito.

  1. Abre tu navegador web y visita la página oficial de descargas: Página de descargas de VirtualBox.
  2. Busca la sección **"VirtualBox platform packages"** y haz clic en el enlace **"Windows hosts"**. Esto descargará el archivo de instalación.
  3. Una vez descargado, haz doble clic sobre el archivo para iniciar el asistente de instalación.
  4. Sigue las instrucciones en pantalla. Generalmente, solo necesitas hacer clic en **"Siguiente" (Next)**, aceptando las opciones predeterminadas hasta finalizar.
2

Descargar ISO de Debian 13

Ahora necesitas el "disco de instalación" para el sistema operativo Linux. Este archivo se llama imagen ISO.

  1. Ve a la página de descargas de Debian: Página de descargas de Debian.
  2. Haz clic en el botón principal de **"Descargar"** para obtener la imagen `netinst`. Es un archivo pequeño que descargará los paquetes necesarios durante la instalación.
3

Crear la Máquina Virtual

Con los archivos listos, es hora de ensamblar tu nueva computadora virtual.

  1. Abre **Oracle VM VirtualBox Manager** y haz clic en el botón **"Nueva"**.
  2. Rellena la información inicial:
    • **Nombre:** "Debian-Servidor"
    • **Tipo:** "Linux"
    • **Versión:** "Debian (64-bit)"
  3. Asigna al menos **2048 MB (2 GB)** de memoria RAM.
  4. Selecciona **"Crear un disco duro virtual ahora"**. Usa las opciones por defecto (VDI, reservado dinámicamente) y asígnale un tamaño de al menos **20 GB**.
  5. Con la nueva VM seleccionada, ve a **Configuración → Almacenamiento**.
  6. Haz clic en el disco óptico **"Vacío"** y, a la derecha, usa el icono de disco para **"Seleccionar un archivo de disco..."**. Elige el archivo ISO de Debian que descargaste.
  7. Haz clic en **"Aceptar"** y luego en **"Iniciar"** para comenzar la instalación de Debian. Sigue los pasos del instalador (idioma, país, contraseña, usuario, etc.). La opción **"Guiado - utilizar todo el disco"** es la más sencilla para el particionado.
4

Instalar MSSQL Server Express - opción 1

Una vez que Debian esté instalado y funcionando, abre la **Terminal** para instalar la base de datos usando los siguientes comandos. Puedes copiar cada bloque con el botón.

1. Importar la clave GPG del repositorio de Microsoft:

curl https://packages.microsoft.com/keys/microsoft.asc | sudo tee /etc/apt/trusted.gpg.d/microsoft.asc

2. Registrar el repositorio de Microsoft para Debian:

echo "deb [arch=amd64] https://packages.microsoft.com/debian/12/prod bullseye main" | sudo tee /etc/apt/sources.list.d/mssql-server.list

3. Actualizar la lista de paquetes e instalar SQL Server:

sudo apt-get update
sudo apt-get install -y mssql-server-express

4. Ejecutar el script de configuración:

Sigue las instrucciones para aceptar la licencia, elegir la edición Express e introducir una contraseña segura para el administrador 'SA'.

sudo /opt/mssql/bin/mssql-conf setup

5. Verificar que el servicio esté activo:

systemctl status mssql-server.service

6. (Opcional) Instalar herramientas de línea de comandos y conectar:

sudo apt-get install -y mssql-tools unixodbc-dev
echo 'export PATH="$PATH:/opt/mssql-tools/bin"' >> ~/.bashrc
source ~/.bashrc
sqlcmd -S localhost -U SA

Después de ejecutar el último comando, te pedirá la contraseña que configuraste. Una vez dentro, puedes ejecutar `SELECT @@VERSION;` y luego `GO` para confirmar la conexión.

5

Instalar MSSQL Server Express - opción 2

Una vez que Debian esté instalado y funcionando, abre la **Terminal** para instalar la base de datos usando los siguientes comandos. Puedes copiar cada bloque con el botón.

1. Crea el directorio de llaves e Importar la clave GPG del repositorio de Microsoft:

sudo mkdir -p /etc/apt/keyrings
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor | sudo tee /etc/apt/keyrings/microsoft.gpg > /dev/null

2. Registrar el repositorio de Microsoft para Debian:

echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/microsoft.gpg] https://packages.microsoft.com/ubuntu/22.04/mssql-server-2022 jammy main" | sudo tee /etc/apt/sources.list.d/mssql-server.list

3. Actualizar la lista de paquetes e instalar SQL Server:

sudo apt-get update
sudo apt-get install -y mssql-server-express

4. Ejecutar el script de configuración:

Sigue las instrucciones para aceptar la licencia, elegir la edición Express e introducir una contraseña segura para el administrador 'SA'.

sudo /opt/mssql/bin/mssql-conf setup

5. Verificar que el servicio esté activo:

systemctl status mssql-server.service

6. (Opcional) Instalar herramientas de línea de comandos y conectar:

sudo apt-get install -y mssql-tools unixodbc-dev
echo 'export PATH="$PATH:/opt/mssql-tools/bin"' >> ~/.bashrc
source ~/.bashrc
sqlcmd -S localhost -U SA

Después de ejecutar el último comando, te pedirá la contraseña que configuraste. Una vez dentro, puedes ejecutar `SELECT @@VERSION;` y luego `GO` para confirmar la conexión.

¡Felicidades! Has completado el proceso.
